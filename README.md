# Relatório — Desafios e Necessidades na Educação Física com Estudantes Autistas

Relatório acadêmico publicado via GitHub Pages sobre os desafios e necessidades enfrentados na Educação Física inclusiva com estudantes autistas.

## Acesse o relatório

[Visualizar o relatório publicado](https://andrelsch.github.io/relatorio-ef-autismo/Relatorio_Desafios_EF_Autismo_1.html)

## Sobre

Este relatório aborda os principais desafios e necessidades identificados na prática da Educação Física com estudantes do espectro autista (TEA), apresentando dados, análises e recomendações para uma abordagem mais inclusiva e eficaz.

## Tecnologias utilizadas

- HTML5
- CSS3
- Chart.js (visualizações de dados)
